# Raster-Schnitt

Teilt ein Bild in mehrere Instagram-Posts, die im Profil ein zusammenhängendes Ganzes ergeben.

## Funktionen

- Raster frei wählbar (z. B. 3×1, 3×3, 2×2) oder per Vorlage
- Formate 3:4, 4:5 und 1:1
- Ausschnitt verschieben und zoomen
- Profil-Vorschau, wie es im Feed aussieht
- Nummerierte Reihenfolge zum Posten
- Kacheln einzeln speichern oder als ZIP

## Nutzung

Einfach `index.html` im Browser öffnen oder auf Vercel deployen. Kein Build-Schritt nötig.

Beim Posten mit Nummer 1 beginnen. Das ist die Kachel unten rechts.

## Datenschutz

Die Bilder werden nur im Browser verarbeitet und nirgends hochgeladen. Kein Logo, kostenlos.
